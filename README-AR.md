# مشروع ساعة الصلاة لأندرويد

مشروع Android Studio للهاتف وAndroid TV. واجهة HTML الأصلية موجودة في `app/src/main/assets/index.html`.

## البناء من الهاتف فقط عبر GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub باسم `SalatClock` واجعله Public للاستفادة من دقائق Actions المجانية.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع ملف ZIP نفسه فقط).
3. افتح تبويب Actions في المستودع، ثم اختر `Build Android APK` واضغط `Run workflow` إذا لم يبدأ البناء تلقائياً.
4. انتظر انتهاء المهمة بنجاح.
5. افتح تشغيل البناء الناجح، وانزل إلى Artifacts، ثم حمّل `SalatClock-APK`.
6. فك ضغط الملف المحمّل لتحصل على `app-debug.apk`، ثم ثبّته على هاتفك. للتلفاز انقل APK إلى التلفاز وثبّته إذا كان Android TV.

ملاحظة: أول بناء يحتاج إنترنت. بعد تثبيت التطبيق، تعمل الوظائف التي بياناتها محلية دون إنترنت؛ الميزات التي تتطلب بيانات أو صوتاً من الإنترنت ستحتاج اتصالاً. مواقيت الصلاة تعتمد على المدينة وطريقة الحساب المحددة داخل التطبيق.
